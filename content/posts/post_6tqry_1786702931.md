这是我的第一篇博客，先把站点是怎么来的记一笔。

站点用 [Hugo](https://gohugo.io/) v0.165.0 从零搭建，没用任何现成主题，模板全是自己写的 Go 模板。

## 为什么从零搭

用现成主题也不是不行，但我想着反正要长期写，不如一次把底子打好：

- 页面结构和样式完全自己掌控，想改哪里改哪里，不用跟主题打架
- 没有多余依赖，静态站点就该轻量
- 顺便把 Hugo 的模板系统整个学了一遍，比光看文档记得牢

## 搭了些什么

- 首页、归档、标签、关于四类页面，导航菜单配好
- 亮/暗模式，用 CSS 变量切换
- RSS 订阅，标签聚合页
- 部署走 GitHub Actions，推送 `main` 自动发布到 GitHub Pages

## 这个站以后放什么

技术学习笔记和项目里踩过的坑，写到哪算哪。
