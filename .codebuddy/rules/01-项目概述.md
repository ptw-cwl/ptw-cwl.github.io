# 项目概述（Hugo 个人博客）

本仓库是个人博客站点，基于 Hugo v0.165.0 Extended 静态站点生成器构建，部署到 GitHub Pages。

## 技术栈

- Hugo v0.165.0 Extended（Windows 版）
- 不使用任何主题，所有模板完全自建（Go 模板语言）
- 纯静态站点，无前端框架、无构建工具链（不涉及 npm / webpack / Vite）

## 常用命令

所有 Hugo 命令必须使用完整可执行文件路径，不要裸写 `hugo`：

```cmd
# 本地预览（含草稿文章）
D:\app\hugo_0.165.0_windows-amd64\hugo.exe server -D

# 生产构建（清理缓存 + 压缩）
D:\app\hugo_0.165.0_windows-amd64\hugo.exe --gc --minify
```

## 目录结构

| 路径 | 作用 | 说明 |
|---|---|---|
| `hugo.toml` | 站点配置 | 含 baseURL、locale、菜单、参数等 |
| `content/posts/` | 博客文章 | Markdown + front matter |
| `content/about/` | 关于页 | 单页内容 |
| `data/tag_display.yaml` | 标签显示映射 | 英文短码→中文显示名（仅渲染查表用）；标签 term 页由 Hugo taxonomy 自动生成，不再手写 `_index.md` |
| `layouts/` | 模板 | Go 模板，含 baseof/index/list/single/terms/404/partials |
| `assets/css/style.css` | 样式 | CSS 变量，支持亮/暗模式 |
| `scripts/new-post.ps1` | 工具脚本 | 新建文章（生成 id 文件名 + front matter） |
| `.github/workflows/hugo-deploy.yml` | 部署 | 唯一 workflow，构建并发布到 Pages |

## 关键约定

- `public/`、`resources/`、`.hugo_build.lock` 为构建产物/缓存，已被 `.gitignore` 忽略，不要手动修改或提交
- `.codebuddy/rules/` 为本项目**团队共享规则，随仓库提交**（未被 `.gitignore` 忽略）。新增/修改规则后需提交入库，并在 `00-规则索引.md` 登记；规则只在会话开始时加载，改动生效需新建对话
- 站点 baseURL 为 `https://ptw-cwl.github.io/`，language 使用 `locale = 'zh-cn'`
- 导航菜单共 4 项（首页/归档/标签/关于），配置在 `hugo.toml` 的 `[menu.main]`
- 文章 front matter 规范（必填字段、时间字段命名、文件命名与 id、生成脚本用法等）详见 `04-文章写作.md`，此处不重复定义；`draft: true` 的文章不会部署到线上
- `hugo.toml` 的 `[params] loadSections` 为内容加载白名单（默认 `['posts', 'about']`），未登记的内容目录不渲染，详见 `04-文章写作.md`

模板写法、样式规范详见 `02-编码规范.md`，部署流程详见 `03-构建与部署规范.md`，文章写法详见 `04-文章写作.md`。
