# 文章写作规范

## 创建新文章

在项目根目录执行（Hugo 完整路径）：

```cmd
D:\app\hugo_0.165.0_windows-amd64\hugo.exe new posts/文章名.md
```

创建后**手动补全 front matter**（Hugo 生成的模板字段可能不完整），按下方字段顺序书写。

## front matter 规范

```yaml
---
title: "文章标题"
date: 2026-08-15
tags: ["标签A", "标签B"]
draft: false
---
```

- 字段顺序固定：`title` → `date` → `tags` → `draft`
- `title`：中文标题加引号；`date`：`YYYY-MM-DD` 格式（本地日期）
- `tags`：2-5 个为宜，使用中文标签（如 `随笔`、`Hugo`），标签会按聚合页展示
- `draft`：写作中设为 `true`（不会部署线上），完成后改为 `false`
- `content/about/index.md` 等单页无需 `tags`

## 正文结构

- 开头 1-2 句点明文章主题（作为摘要展示）
- 使用 `##` 划分章节，标题层级规范，不跳级（`##` 后接 `###`，不用 `#` 做主标题）
- 列表、代码块等保持合理留白；代码块必须标注语言（```go / ```html / ```css / ```bash）
- 链接使用 Markdown 标准写法；站内文章链接优先用相对路径或 `.RelPermalink`

## 图片处理

- 图片放入 `static/images/`（该目录如不存在则创建），正文引用：

```markdown
![图片说明](/images/文件名.png)
```

- 图片命名使用英文小写 + 连字符（如 `hugo-arch.png`），尺寸尽量压缩（建议 < 500KB）

## 发布流程

1. 写作完成，`draft` 改为 `false`
2. 本地预览验证：`D:\app\hugo_0.165.0_windows-amd64\hugo.exe server -D`（访问 http://localhost:1313/）
3. 确认渲染正常（标题、标签链接、代码高亮、暗色模式）后，提交信息使用 `feat: 新增文章《xxx》`（见 `02-编码规范.md` 提交规范）
4. 推送后 GitHub Actions 自动部署，访问线上地址验证

语言表达风格（语气、用词、句式）详见 `05-写作风格.md`。
