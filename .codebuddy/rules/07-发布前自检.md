# 发布前自检清单（内容创作）

本文件汇总文章发布前必须逐条核对的检查项。各项的**详细规范定义**见对应规则文件，此处只列清单不展开：

- 标签：见 `04-文章写作.md`
- 描述 / 正文：见 `04-文章写作.md`、`05-写作风格.md`
- 合规：见 `06-内容合规.md`
- 构建与部署：见 `03-构建与部署规范.md`

## 一、Front matter 检查

- [ ] `title` / `id` / `createTime` / `updateTime` / `description` 五个必填字段齐全
- [ ] `id` 与文件名前缀一致（如 `post_xxx_时间戳.md` → `id: post_xxx_时间戳`）
- [ ] `tags` 全部为**小写英文短码**，且已在 `data/tag_display.yaml` 登记（大小写敏感，大写会漏检）
- [ ] 新增标签时：先在 `data/tag_display.yaml` 登记中文显示名，再用于文章
- [ ] `description` 控制在 120 个汉字内（超出会被 `baseof.html` 的 `substr 0 120` 截断）
- [ ] 非草稿文章 `draft: false`；草稿未发布时保持 `draft: true`

## 二、正文检查（去 AI 味 / 风格）

- [ ] 无"在当今社会""值得一提的是""总之"等 AI 味套话（详见 `05-写作风格.md`）
- [ ] 开头直入主题，不与标题/正文脱节
- [ ] 用词具体、示例真实，无空泛总结段
- [ ] 代码/命令示例中的真实路径、密钥、token 已打码

## 三、合规检查

- [ ] 内容符合本站"个人技术 / 经验分享、实用为主"定位（详见 `06-内容合规.md`）
- [ ] 引用的图片 / 素材来源合规，无版权风险
- [ ] 涉及个人信息已脱敏

## 四、平台分发（syndicate）

- [ ] 若文章 `syndicate: true`：对应 `syndicate/<平台>/<标题>.md` 草稿已生成且为最新人工修订版
- [ ] 平台字段状态自洽：`converted` / `publish` / `status` 与发布脚本约定一致（`status=published` 须有非空 `pid` 且 `publish=true`，见 `04-文章写作.md`）
- [ ] 转换草稿已随仓库提交（`syndicate/` 默认入库，非 `.gitignore` 忽略项）

## 五、构建与发布

- [ ] 本地执行清理式构建：`rmdir /s /q public` 后 `hugo --gc --minify`，**零报错零警告**
- [ ] 运行 `scripts/check-tags.ps1` 校验标签，输出 `OK`（若被 `hugo server` 占用先关进程再删 `public/`）
- [ ] 日常改动提交到 `dev`；需要上线时合并 `dev` → `main` 并推送 `main`，等待 Actions 完成后在线上验证首页 / 文章页 / 标签中文名 / RSS / sitemap
